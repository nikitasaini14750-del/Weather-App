# Weather-App
# 🌤️ Weather App

A responsive and user-friendly Weather Applicationbuilt using **HTML5, CSS3, and JavaScript**. This application fetches real-time weather data using the **OpenWeather API** and displays weather information for any city around the world.


# 📖 Project Overview

The Weather App allows users to search for any city and instantly view its current weather details.

It displays:

- 🌡️ Temperature
- ☁️ Weather Condition
- 📝 Weather Description
- 💧 Humidity
- 🌬️ Wind Speed

This project demonstrates the use of **API Integration**, **JavaScript Fetch API**, and **Responsive Web Design**.

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Weather-App.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. Enter a city name.

5. Click **Search**.
